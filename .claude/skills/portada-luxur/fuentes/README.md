# Letra de la portada

`Safira-March-Medium.otf` — Safira March Medium, de Din Studio (din-studio.com), versión 1.000.
Es una letra **comercial** (su tabla `name` dice «Commercial use font»). Está en git porque el dueño
del estudio tiene licencia y pidió versionarla (2026-10-11); es una copia byte a byte de la que
entregó.

Solo la usa `scripts/portada.py`, para la locación de la portada. Está en `.claude/skills/`, que es
zona de estudio (`herramientas/zonas.mjs`): no viaja al producto. No se mueve a
`remotion/public/fuentes/`, que sí viaja.
