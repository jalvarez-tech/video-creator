- **Dinero** — `Cash Register ×3`, `cash ting`, `Mario Coin`. → leads/ventas.

- **Cámara** — varios `camera shutter/flash`. **Papel** — `Paper Flip/Ripping/Slide`, `crumpled paper`.
- **Boom / impacto / build-up** — `01 Boom`, `big cinematic impact`, `space impact`, `bass drop`, `BUILD-UP`, `Ascending`. → énfasis, risers.

## 🧹 Notas de limpieza y calidad

- **`.mp4` (12 archivos) → son VÍDEOS, no audio.** Si solo quieres el sonido, extrae el audio:
  ```bash
  ffmpeg -i "05-BOOM (IMPACTO)/Vine Boom dramatico.mp4" -vn -acodec libmp3lame "05-BOOM (IMPACTO)/Vine Boom dramatico.mp3"
  ```
  Están en: 05-BOOM, 14-DING, 19-EXTRAS (teclado iPhone), 25-MEMES (×6), 33-TERROR, 37-OTROS (×2).
- **`.trashed-*` (4 archivos) → basura de Android a medio borrar** (en 18-EXPRESIONES ×2, 23-GRITOS, 34-TERROR Y DRAMA). Se pueden eliminar.
- **Solapamientos** (categorías casi equivalentes): 32-SWOSH ≈ 36-WHOOSH ≈ 35-TRANSICIÓN · 08-CINEMÁTICA ≈ 09-CINEMÁTICA RISER · 13-DINERO ≈ 27-MONEDA · 33-TERROR ≈ 34-TERROR Y DRAMA. **37-OTROS duplica muchas** (cámara, whoosh, pop, click, dinero, papel, boom, glitch); su valor único = **Sci-Fi/UI/Data y notificaciones de app**.
- **Formato:** para editar, prefiere **`.wav`** (sin pérdida) cuando exista; el `.mp3` va bien para el resultado final.
- **Prioridad de uso profesional:** 36/32/35 (transiciones), 05 (impactos), 29/14/10 (aparición/UI), 12/13/27 (datos/dinero), 09/11 (build-ups). Las de memes (25/23/30/21/06) para contenido más informal.

## 🔧 Cómo usarlos en Remotion

**Recomendado — motor de cues** (sincronización + volumen + fades + `reason` obligatorio):

```tsx
import { PistaSonido } from "./plantillas/sound/PistaSonido";
import { cue } from "./plantillas/sound/cues";

const cues = [
  cue("mg-in", "whoosh", "light", 200, 16, "Entra el gráfico (movimiento)"),
  cue("count", "impact", "chime", 320, 18, "El contador llega al valor final", { priority: "high" }),
];
<PistaSonido cues={cues} />   // por ENCIMA del vídeo; la voz manda
```

Las 38 variantes (`light`, `pop`, `glitch`, `scribble`, `liquid`, `chime`…) están mapeadas a
archivos reales en el objeto `SFX` de `cues.ts`. Elige la variante con el
[recetario por motion graphic](../manuales/diseno-sonoro/recetario-motion-graphics.md).

**Manual — un solo `Audio`** (para pruebas rápidas):

```tsx
import { Audio, Sequence, staticFile } from "remotion";
<Sequence from={200}>
  <Audio src={staticFile("sfx/whoosh-light.mp3")} volume={0.3} />
</Sequence>
```

Ajusta `volume` (0–1) para no tapar la voz; usa `startFrom`/`endAt` (en frames) para recortar.

> Dime en qué momentos del vídeo quieres SFX y te los dejo colocados y sincronizados.
